# Kashi Thaal

Banarasi thali restaurant ki website (Lanka, Varanasi). Static site: HTML + CSS + JS, koi build step nahi.

- **Content badalna:** sirf `js/data.js` (naam, phone, WhatsApp, address, timings, menu, prices, reviews, links).
- **Photos:** `assets/img/` mein apni photo daalo, `data.js` mein naam badlo.
- **Hero frames:** `assets/frames` (desktop, 150) aur `assets/frames-m` (phone, 75), `hero.mp4` se ffmpeg se bane.
- Local chalane ke liye: `python3 -m http.server` phir `http://localhost:8000`.
